# Project-level follow-ups have no home

Tasks live only in goals, so a follow-up that belongs to the project as a whole has nowhere to go.
Example: Geoff deferred rewriting the vision ("not yet"; revisit once the workstreams settle). That
follow-up is real, but it belongs to no goal. For now it's recorded only in the wiki log, where
`/next` and `/lint` might not notice it.

**Options:**
- a project-level `tasks.md`
- a standing "project upkeep" goal
- letting `/next` and `/lint` read deferred items from the log

**Harness implication (H-001):** not all of a PM agent's work items belong to a goal. Examples
include upkeep of the vision and periodic re-validation of context.
