# Inbox

Raw, unfiled learnings. Anyone (a human or an agent) drops things here. Name each item
`YYYY-MM-DD-slug.md`. It can be any shape: a note, a pasted excerpt, a link, a meeting takeaway.

Optional frontmatter:

```
---
source: <where it came from>
goal: <NNN, if you think it's goal-specific>
tags: [scaffold-friction, ...]
---
```

`/ingest` files each item into the project wiki or a goal's `context/`, then moves it to
`_processed/`.
