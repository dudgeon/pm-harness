# Vision

> Draft seeded from the kickoff conversation. Sharpen before relying on it.

Build and deploy an **AI product manager**, most likely a deployed agent or agent orchestrator, that holds a project's vision,
constraints, priors, and goals, and that keeps them coherent as they evolve. It should sharpen
vague intent into clear goals. It should notice when things contradict and ask about it. It should
turn what's learned along the way into shared context that benefits every goal.

## How we'll get there

- We expect a lot of R&D across **many candidate harness designs** before we settle on one to build.
- We manage this project with **project-scaffold-v1**, a markdown file structure plus skills.
  It is not the harness, but it's worth keeping and evolving (DEC-003, DEC-004).

## Open

- Who is the user? (a solo PM, a PM team, an eng lead acting as PM?)
- What does "deployed" mean? (Claude Code plugin, hosted agent, template repo, something else?)
- How will we know it works? (success measures)
