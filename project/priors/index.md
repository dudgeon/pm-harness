# Priors and sources

Context **outside** this project that the project lives in and must interoperate with: org
strategy, adjacent systems, research, and prior decisions made by others.

**Rules:**
- This folder is read-only for agents. Propose changes, and edit only with approval.
- Priors are considered positions. They outrank most evidence, but they can be overturned.
  Overturning one may need stakeholders outside the project PM's authority.
- Contradictions between priors and anything else go in `../open-questions.md`.
