# /rollup

1. For each `project/goals/NNN-*/` folder, in numeric order (skip `_template`): read the
   `goal.md` frontmatter and `tasks.md`.
2. Rewrite `project/tasks.md` completely:
   - Start with the header comment `<!-- GENERATED by /rollup. Do not edit; edit goals/*/tasks.md instead. -->`
     followed by `_Last rolled up: YYYY-MM-DD_`.
   - Add one section per goal: `## NNN · title (status)`, containing the goal's tasks verbatim,
     with their tags kept.
   - Put `active` goals first, then `draft`, then `paused`. For `done` and `dropped` goals, list
     only the ones that still have open tasks, and flag them.
   - Finish with a short **Summary**: open and done counts per goal, and a list of blocked tasks
     with their `Q-NNN`.
3. **Deliverables ladder.** Compare each goal's `deliverables.md` with `project/deliverables.md`.
   Report any gaps, but don't edit `project/deliverables.md` without asking.
4. Never edit goal `tasks.md` files during a rollup. If a task looks wrong, say so.
